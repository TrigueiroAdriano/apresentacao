Visão Geral do Sistema
O que o ERP Metalurg controla e gerencia
📦
Programação de Peças (PPCP)
Fila de produção com priorização e atualização em tempo real via Server-Sent Events (SSE). Auditoria completa de cada operação.
📝
Lançamentos de Turno
Registro de peças processadas por operador, máquina e linha de produção. Controle de retrabalho e roteamento de peças.
🧪
Controle Químico de Banhos
Análises físico-químicas dos 11 tanques das linhas LFOS-0201 e LFOS-0202. Ações corretivas e reanálise pós-reforço.
🔴
Paradas de Máquina
Registro, liberação e cálculo automático de downtime em minutos. Dashboards de disponibilidade e OEE.
💧
Consumo de Água
Leituras de hidrômetro por turno e linha. Cálculo automático de consumo e controle de desvios com justificativa.
👥
Gestão de Usuários
Criação, controle e remoção de usuários com RBAC (Role-Based Access Control) de 6 perfis distintos.

Banco de Dados
Schema PostgreSQL (Supabase) — 10 tabelas relacionais
-- Schema principal do ERP Metalurg (supabase_schema.sql)

-- 1. Usuários do sistema
CREATE TABLE public.users (
  id           SERIAL PRIMARY KEY,
  username     VARCHAR(100) UNIQUE NOT NULL,
  password     VARCHAR(255) NOT NULL,  -- hash bcrypt 12 rounds
  nome         VARCHAR(150),
  cargo        VARCHAR(100),
  role         VARCHAR(50)  DEFAULT 'operador',
  free         INT,          -- código de identificação físico
  created_at   TIMESTAMP WITH TIME ZONE
);

-- 2. Lançamentos de produção
CREATE TABLE public.production_logs (
  id, data, linha, maquina, codigo, lote, quantidade,
  retrabalho, vai_jatear, ja_jateada, horario_entrada,
  horario_saida, diario_de_bordo, free, numero_balde,
  programming_id, created_at
);

-- 5. Programação de Peças (PPCP)
CREATE TABLE public.piece_programming (
  id             SERIAL PRIMARY KEY,
  peca           VARCHAR(150) NOT NULL,
  lote           VARCHAR(100),
  quantidade     INT,
  linha          VARCHAR(100),
  data_programada DATE,
  status         VARCHAR(50) DEFAULT 'fila',
  ordem          INT DEFAULT 0   -- posição na fila (menor = primeiro)
);

-- 4. Paradas de máquina
CREATE TABLE public.machine_stops (
  timestamp_inicio TIMESTAMP WITH TIME ZONE,
  status           VARCHAR  DEFAULT 'parada', -- 'parada' | 'liberada'
  timestamp_fim    TIMESTAMP WITH TIME ZONE,
  duracao          INT      DEFAULT 0        -- em minutos
);

-- 7. Parâmetros de análise dos banhos
CREATE TABLE public.bath_parameters (
  tank            VARCHAR(50)  NOT NULL,
  line            VARCHAR(50)  NOT NULL,  -- 'LFOS-0201' | 'LFOS-0202'
  min             NUMERIC,
  max             NUMERIC,
  unit            VARCHAR(20),             -- '%','°C','pH','ml','g/L','mbar'
  reinforcements  JSONB                    -- ações corretivas
);

Guia de Preenchimento
Passo a passo para cada módulo do sistema
🔑 Login no Sistema
Todos os perfis
  1. Acesse a URL do sistema (http://localhost:3001 em desenvolvimento)
  2. Informe o Usuário no campo correspondente
  3. Informe a Senha e clique em Entrar
  4. O sistema redireciona automaticamente para o dashboard conforme seu perfil de acesso
📝 Lançamento de Produção de Turno
Quem pode: Operadores (exceto visitantes e programadores)
  1. Acesse Lançamentos de Turno no dashboard
  2. Preencha os obrigatórios: Máquina, Código da Peça, Lote, Quantidade
  3. Configure conforme a situação: Linha (Jateamento/Fosfatização), Retrabalho, Vai Jatear, Já Jateada
  4. Informe Horário Entrada/Saída, Número do Balde e Diário de Bordo (observações livres)
  5. Clique em Salvar Lançamento — o registro aparece instantaneamente na tabela
📦 Cadastro de Peça na Fila PPCP
Quem pode: Admin, Programador e operadores
  1. Acesse Programação de Peças
  2. Clique em Nova Programação
  3. Preencha: Peça, Lote, Quantidade, Linha, Data Programada
  4. Clique em Adicionar à Fila — a peça entra automaticamente no final com o próximo número de ordem
  5. Para reordenar (Admin/Programador): use os botões ▲/▼ na linha da peça
  6. Para atualizar status: clique no campo de status e selecione o estado no fluxo de produção
🧪 Registro de Análise de Banho
Quem pode: Operador de Fosfato e Admin
  1. Acesse Controle de Banhos
  2. Selecione Linha (LFOS-0201 ou LFOS-0202), Tanque e Turno
  3. Para cada parâmetro listado, informe o valor medido — o sistema sinaliza se está dentro ou fora da faixa
  4. Se fora da faixa: leia e aplique a ação corretiva prescrita pelo sistema (adicionar produto, diluir, etc.)
  5. Registre os valores após reforço e a reanálise pós-correção
  6. Adicione Diário de Bordo e Registro de Análise
  7. Clique em Salvar Análise
🔴 Registro de Parada de Máquina
Quem pode: Todos os operadores (exceto Programador e Visitante)
  1. Acesse Paradas de Máquina
  2. Clique em Registrar Parada
  3. Selecione a Máquina, informe o Motivo e adicione Observação se necessário
  4. Data e hora são preenchidos automaticamente com o momento atual (editáveis se necessário)
  5. Após o reparo: clique em Liberar Máquina — o sistema calcula a duração automaticamente em minutos
